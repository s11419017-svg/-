# 🏰 雨果世界 2D 平台動作遊戲：標準化製作流程規範（Production Workflow Pipeline）

為避免功能開發過程中出現粗糙拼湊、數值失衡、假碰撞或幽靈狀態，所有新機制、敵方單位、地形互動與動態事件開發均需遵循本標準化五步工程流程：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. 概念與威脅向量設計 (Threat Vector & Mechanics Specification)              │
│    • 定義單位定位（如：德納第 = 陰險狡詐騷擾型、憲兵 = 直線壓迫、隊長 = 裝甲盾牌） │
│    • 設計對應的破局克制手段（Counterplay），杜絕無解局面                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2. 確定性狀態機與幾何掃掠 (Deterministic State Machine & Swept-AABB)          │
│    • 狀態劃分：Patrol, Alert, Flank, AbilityCast, Stagger, Flee, Dead        │
│    • 嚴格採用 Swept-AABB 碰撞檢測與公差容錯，杜絕穿模與假碰撞                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 3. 戰術協同 AI 與動態拉距 (Tactical Behavior Tree & Crowd Spacing)          │
│    • 實體感知半徑（視線 Line of Sight、距離測算、同高度判定）                   │
│    • 戰術協同（吹哨呼叫增援、包抄夾擊、預判投擲速度補償）                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ 4. 多感官打擊感與視聽回饋 (Juice, Sound Synthesis & Screen Feedback)         │
│    • 包含 Hit-Stop（頓幀）、Screen Shake（震動衰減）、Particles（粒子物件池）  │
│    • Web Audio API 專屬音效合成（無外部音頻加載延遲）與 Web Haptics 觸覺反饋   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 5. 生命週期修剪與回歸驗證 (Lifecycle Pruning & Regression Test)               │
│    • 離屏物體自動修剪（Safe Memory Pruning），零 GC 壓力                       │
│    • TypeScript 嚴格型別檢查 (tsc --noEmit) 與 60 FPS 幀率驗證                 │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 🎯 實體威脅矩陣（Enemy Threat Vector Matrix）

| 單位 | 角色定位 | 核心威脅技能 | 玩家破解手段（Counterplay） |
| :--- | :--- | :--- | :--- |
| **😈 德納第 (Thénardier)** | 陰險狡詐、地痞偷襲 | **撒菱地刺 (Caltrops)**、**短刀突刺 (Dagger Charge)**、**迷霧黑煙 (Smoke)**、**偷竊並反咬 (Pickpocket)** | 踩踏/彈弓暗算、空中二段跳跨越、利用火藥桶震飛 |

| **💣 國民衛隊擲彈兵 (Grenadier)** | 遠程預判、戰術壓制 | **預判提前量催淚彈**、**近身後撤滑步** | 衝刺近身突擊、空中翻滾避開落點、彈弓截殺 |
